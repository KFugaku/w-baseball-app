# 選手成績の集計仕様

Issue #14 / #39 で実装した選手成績は、NPB「記録の計算方法」と公認野球規則 9.17〜9.19を基準にする。

- NPB 記録の計算方法: https://npb.jp/scoring/calculation.html
- 公認野球規則 9.00 記録に関する規則: https://npb.jp/scoring/officialrule_900.pdf

## 打撃成績

- 打率 = 安打 ÷ 打数
- 出塁率 = （安打 + 四球 + 死球）÷（打数 + 四球 + 死球 + 犠飛）
- 長打率 = 塁打 ÷ 打数。単打1、二塁打2、三塁打3、本塁打4として計算する
- OPS = 出塁率 + 長打率
- 四球・死球・犠飛・犠打は打数に含めない

率はDBでは丸めずに保持し、画面表示時に小数第3位へ丸める。分母が0の場合は `—` と表示する。

## 投球成績

- 投球回は記録したアウト数を3で割って表示する
- 防御率 = 自責点 × 9 ÷ 投球回（アウト数を使う場合は 自責点 × 27 ÷ アウト数）
- 登板、与四球、奪三振、被安打、自責点は完了した打席イベントから集計する

## 勝利・敗北・セーブ・ホールド

試合終了操作時に確定する。

- 先発勝利: 予定回数の半分を切り上げた回数以上を投げ、リードして降板し、そのまま勝利した場合。9回制は5回、4回制は2回、3回制は2回
- 救援勝利: 味方が最後に勝ち越す直前まで投げ、以後リードしたまま勝利した場合
- 敗戦: 決勝点となった走者を出した責任投手
- セーブ: 勝利チームの最後の投手、勝利投手ではない、1アウト以上、リード時登板を満たし、3点以内で1回以上・2打者連続本塁打で同点となる場面・3回以上のいずれか
- ホールド: 先発・勝利・セーブ投手ではなく、リード時に登板して1アウト以上を取り、同点または逆転を許さず降板し、セーブと同じA/B/C条件のいずれかを満たす

走者には出塁時の責任投手を紐付けて引き継ぐ。そのため、投手交代後に生還した走者も、出塁を許した投手の失点および敗戦判定に使われる。

## データの扱い

打席を取り消した場合はイベントを削除せず `reverted_at` を記録し、集計対象から除外する。履歴とRealtime通知を残したまま、成績の二重計上を防ぐためである。

現在の試合入力で記録できる得点はすべて自責点として扱う。失策と非自責点を入力する機能を追加する場合は、`game_event_runs.is_earned` を操作できる専用UIを用意する。

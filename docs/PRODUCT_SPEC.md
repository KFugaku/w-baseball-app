# 草野球速報 プロダクト仕様

## 1. 目的

草野球の試合について、観戦者が現在の状況をすぐ把握でき、運営者がスマートフォンやPCから簡単に更新できることを目的とします。

## 2. 想定利用者

- **観戦者**: 試合一覧、スコア、カウント、出場選手、守備位置、試合経過を閲覧する
- **試合運営者**: 管理者モードで試合、メンバー、打順、守備位置、スコア、打席結果を更新する

## 3. 現在の機能

### 3.1 試合一覧

- 当日の試合を一覧表示する
- 各試合の名称、対戦チーム、ステータス、得点を表示する
- 試合を選択すると試合詳細へ移動する
- 管理者は新しい試合を追加・削除できる

### 3.2 メンバー・チーム管理

- 当日のメンバーを一覧表示する
- 管理者はメンバーを追加・編集・削除できる
- 管理者は先攻・後攻チームの打順とベンチを編集できる
- 管理者は守備位置を変更できる

### 3.3 試合詳細

- イニング、表裏、試合ステータス、得点を表示する
- ボール、ストライク、アウト、走者を表示する
- 現在の打者と投手を表示する
- 打順、ベンチ、守備位置を表示する
- 打席結果と試合経過を新しい順で表示する

### 3.4 試合更新

- 管理者は投球結果と打席結果を入力できる
- 打席結果に応じてカウント、アウト、走者、得点を更新する
- 攻守交代と直前操作の取り消しができる

### 3.5 管理者モード

- 閲覧者には更新操作を表示しない
- パスワード入力後に更新操作を表示する
- 管理者モードからログアウトできる

## 4. 画面と基本フロー

```text
試合一覧
├─ 試合を選択 ─→ 試合詳細（閲覧）
├─ 管理者ログイン ─→ メンバー管理
└─ 管理者ログイン ─→ 試合作成 ─→ 打順・守備設定 ─→ 試合更新
```

試合詳細では、運営者の入力がスコアボード、カウント、走者、打席結果、試合経過へ反映されます。

## 5. 主要なデータ

| データ | 主な項目 |
| --- | --- |
| 試合 | ID、試合名、ステータス、先攻、後攻、得点、チームカラー |
| チーム | チーム名、カラー、出場選手、ベンチ |
| 選手 | ID、姓、名、守備位置、打率 |
| 試合状況 | イニング、表裏、B/S/O、打者、走者、得点 |
| プレー | イニング、選手、打席結果 |

## 6. 非機能要件

- スマートフォンとPCの両方で主要操作ができる
- 閲覧操作と更新操作を明確に区別する
- 色だけに依存せず、文字でも状態を判別できる
- 主要画面が一般的なモバイル回線でも実用的な時間で表示される
- 変更はlint・buildに成功し、PRで追跡できる

## 7. 現在の制約

- データはフロントエンドのメモリ上にあり、再読み込みで初期化される
- 複数端末へのリアルタイム同期はない
- 管理者認証はデモ用で、セキュアな認証・認可ではない
- イニング別得点など、一部表示はサンプルデータを含む
- 自動テストは未導入

## 8. 今後の検討事項

優先順位はIssueで決定します。

1. データベースとAPIによる永続化
2. 安全な管理者認証と権限管理
3. 複数端末へのリアルタイム配信
4. 正式な野球ルールに基づく得点・走者・打順処理
5. 自動テストとE2Eテスト
6. アクセシビリティとレスポンシブ表示の改善
7. 大会、シーズン、複数チームへの拡張

## 9. 仕様変更の扱い

仕様を変更する場合は、Issueに背景・変更内容・受け入れ条件を書き、この文書も同じPull Requestで更新します。判断が保留の項目は実装へ混ぜず、Issueの「未決事項」として残します。
